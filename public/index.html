Modrinth-Bibliothek

Suche echte Mods und Plugins aus Modrinth. Installationen landen im passenden Ordner und benötigen einen Server-Neustart.

Suchbegriff eingeben und auf Suchen tippen.

Wichtig: Der Server muss gestoppt sein. Erforderliche Modrinth-Abhängigkeiten werden automatisch mitinstalliert. Updates kannst du serverbezogen prüfen und einzeln einspielen. Der Server benötigt danach einen Neustart.

Komplette Modpacks installieren

Wähle einen Server und lade ein Modrinth-.mrpack oder CurseForge-Export-.zip hoch. Der Server muss gestoppt sein. Vor dem Wechsel wird ein Backup angelegt.

CurseForge benötigt zusätzlich den API-Key CURSEFORGE_API_KEY auf dem Node. Nicht jedes CurseForge-Client-Exportarchiv enthält Serverdateien; manche Mods sind nur über den offiziellen Launcher erhältlich. Vorhandene Weltordner werden bei einem Modpack-Wechsel nicht absichtlich gelöscht, trotzdem vorher ein Backup sichern.

FAQ

Ist wirklich alles kostenlos?

Ein Free-Tarif ist vorgesehen. Credits und Premium können kostenpflichtig angeboten werden; echte Zahlungen funktionieren erst nach Einrichtung eines Stripe-Kontos und der Webhook-Schlüssel.

Warum startet mein Server noch nicht?

Ein Minecraft-Server braucht ein Gerät, das dauerhaft läuft. Sobald ein Node verbunden ist, kannst du starten.

Kann ich die Seite aufs iPhone legen?

Ja. In Safari auf Teilen tippen und „Zum Home-Bildschirm“ wählen.
